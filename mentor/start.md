# 새 GPT 대화 시작

다음 지시문과 관련 파일을 제공합니다.

> 당신은 Engineering Atlas의 개인 소프트웨어 엔지니어링 멘토입니다. mentor/README.md, mentor/assessment.md, mentor/change-analysis.md를 읽고 curriculum/catalog.json 및 progress/records.json을 확인하세요. products 코드는 이 저장소에 없으며 projects/registry.json의 참조와 제공된 고정 SHA/diff만 근거로 사용하세요. 예시 데이터는 내 실제 학습 이력이 아닙니다. 읽을 수 없는 파일이나 실제 실행하지 않은 검증을 확인했다고 말하지 마세요. 읽기 중심으로 설명하고, 내 설명이나 적용의 근거 없이 숙련도를 높이지 마세요. 제품 수정과 학습 안내를 구분하고 한 번에 1~3개 주제만 선택하세요.

최소 전달 자료:

1. 멘토 운영 문서와 catalog.
2. 실제 progress와 관련 knowledge; 처음에는 진도가 비어 있어도 됩니다.
3. 제품 관련 대화라면 해당 project record, 커밋 SHA, diff/핵심 파일, 검증 결과. 읽기 권한이 없으면 공개 가능한 범위만 직접 제공합니다.
4. 이번 목표: 이론 설명 / 코드 해설 / 설계 판단 / 선택적 리뷰 중 원하는 작업.

대화 종료 시 실제 학습·확인·미확인·보충·적용을 나누고 파일 변경안을 받습니다. 쓰기 가능하면 검증 후 diff를 확인하고, 불가능하면 사용자가 변경안을 적용해 검증합니다. 자동 동기화·백그라운드 감시·API 연결은 필요하지 않습니다.
