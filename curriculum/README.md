# 커리큘럼

[catalog.json](catalog.json)이 개념·영역·참고 자료의 유일한 메타데이터 원본입니다. 18개 필수 영역을 모두 포함하며, 개념별로 한국어·영어 이름, 짧은 설명, 선수/관련 ID, 목표, 적용 사례, 단계, 참고 자료 ID를 관리합니다. 전체 강의 본문은 학습 시 knowledge에 작성합니다.

## 권장 단계

1. **기초 읽기와 실행**: 값·제어 흐름·함수·모듈·메모리·Git·단위 테스트·요구사항.
2. **코드 해석과 품질**: 자료구조·복잡도·디버깅·설계·객체/함수형·웹·데이터 모델·보안 기초·CI·LLM 기초.
3. **설계와 운영 판단**: 아키텍처·동시성·트랜잭션·인증·배포·신뢰성·성능·에이전트·평가.
4. **응용과 종합 검증**: 실제 부하와 제약 아래 확장성 판단. 다른 영역도 실제 제품에 적용하며 Level 4 근거를 쌓습니다.

단계는 안내이며 숙련도 Level과 다릅니다. `prerequisites`는 먼저 이해할 개념을 가리키는 DAG입니다. `related`는 함께 볼 관계이며 순환을 허용합니다. 예를 들어 `prog-values → prog-functions → prog-modules → design-cohesion`과 `prog-functions → test-unit → design-refactoring`은 두 학습 경로가 합쳐지는 구조입니다. 모든 개념을 한 줄 순서로 강의하지 않습니다.

멘토는 현재 문제와 검증된 선수 지식을 함께 보고 경로를 고릅니다. 추천된 개념이 아직 어려우면 필요한 선수 부분만 보충하고 중요도가 낮으면 보류합니다. 출처의 범위는 입문서·공식 문서·검증된 기술 자료이며 개별 개념과의 적합성은 강의 시 해당 절을 다시 확인합니다. 외부 URL 상태 검사는 CI 범위가 아닙니다.
