# 지식 사전

실제로 다룬 개념만 `<concept-id>.md`로 추가합니다. [지식 템플릿](../templates/knowledge.md)을 복사하고 사용하지 않은 절은 생략합니다. 파일명 ID는 catalog에 있어야 합니다. 개념의 메타데이터는 [catalog](../curriculum/catalog.json)를 참조하고 중복 관리하지 않습니다.

정의·필요성·해결 문제·원리·짧은 교육용 코드·오해·관련 개념·프로젝트 적용·자료를 점진적으로 축적합니다. 제품 코드 전체를 복사하지 않고 cases와 커밋을 참조합니다. 교육용 코드는 실제 제품 코드와 구별합니다. 이 문서가 존재한다고 이해가 검증된 것은 아닙니다.
