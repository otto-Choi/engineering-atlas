# 초기 구축 결과와 최종 점검

## 구현 범위

| 요구사항 | 구현 위치와 확인 결과 |
| --- | --- |
| 구조와 사용법 | 루트 README, 책임별 README, 템플릿, 데이터 계약 |
| 전체 커리큘럼 | catalog에 필수 18개 영역·67개 주요 개념; 메타데이터와 DAG |
| 지식 사전 | concept ID 파일명 규칙과 점진적 템플릿; 대량 강의 없음 |
| 학습 상태 | 검증/추정 수준 분리, 학습/미확인/보충/적용, 날짜와 근거 |
| 멘토 운영 | 이론·코드·설계·관리의 네 역할, 개입/보류 기준, 변경 분석 8단계 |
| 여러 제품 연결 | registry와 project ID, 전체 SHA, PR 번호, 파일, 검증 결과 |
| 포트폴리오 | 원본 사례 참조, 판단 주체·한계·공개 점검, 후보 상태 관리 |
| 자동 검사 | Python 표준 라이브러리, push/PR/manual GitHub Actions |
| 예시 분리 | 여섯 기초 개념·가상 제품 1개·사례 1개·후보 1개; is_example=true |
| 실제 상태 보존 | 실제 project/progress/case/portfolio 배열은 모두 비어 있음 |

이번 점검은 구현 후 요구사항과 대조해 수행했습니다. 별도 에이전트나 AI 리뷰 자동화를 실행하지 않았습니다. 기록의 원본과 참조를 분리했으며 제품 코드·서버·외부 패키지를 추가하지 않았습니다.

## 실제 로컬 검증

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

검증 스크립트 통과, **36개 unittest 통과**를 확인했습니다. 정상 데이터뿐 아니라 중복 ID, 누락된 메타데이터, 존재하지 않는 개념/제품/사례, 선수 순환과 자기 참조, 잘못된 SHA/PR/날짜/URL/JSON, 문서 파일/앵커 오류, 실제/예시 교차 참조, 근거 없는 수준 상승, 공개 점검 누락을 주입해 실패 탐지를 확인했습니다. 실제 namespace에 완전한 임시 데이터를 넣는 양성 테스트도 포함합니다. 테스트용 가상 데이터는 임시 디렉터리에만 생성되고 삭제됩니다.

GitHub Actions 설정은 같은 두 명령을 Python 3.12에서 실행합니다. 위 결과는 로컬 실행 결과이며 GitHub에서의 실행 성공을 대신 주장하지 않습니다.

## 참고 자료 확인

catalog의 19개 출처 URL은 구축 과정에서 HTTP 응답 200을 확인했습니다. Pro Git 사이트와 예전 OpenAI 문서 주소가 실행 환경에서 403을 반환해, 각각 확인 가능한 공식 Pro Git 원문 저장소와 현재 OpenAI 문서 주소를 사용했습니다. 이는 당시 접근 가능 여부를 확인한 것이며, 모든 문서 내용을 전수 검토하거나 미래 URL 유효성을 보증한 것은 아닙니다. 멘토는 실제 강의 시 해당 절과 설명의 적합성을 다시 확인합니다. 외부 URL 검사와 네트워크 요청은 CI에 넣지 않았습니다.

## 의도적으로 제외한 범위와 한계

요구사항에 따라 웹앱·DB·벡터/RAG·MCP·멀티 에이전트·자동 GPT 호출·모든 커밋 자동 리뷰·숙련도 자동 상승·GitHub Pages·제품 코드 수정은 구현하지 않았습니다. 초기 학습 기반에 필요하지 않기 때문입니다.

검사기는 참조·형식의 오류를 찾지만 학습자의 실제 이해, 커밋의 실재, 성과의 진실성, 공개 권한이나 비밀정보 부재는 보증하지 않습니다. [데이터 계약](data-contract.md)의 검사 범위와 [공개 기준](publication.md)에 따라 사람과 멘토가 검토합니다.

## 다음 사용 절차

[멘토 시작 지침](../mentor/start.md)을 GPT에 제공하고 catalog와 현재 progress를 읽게 합니다. 제품이 없다면 기초 이론부터 시작하고, 제품이 생기면 registry에 등록해 실제 커밋 SHA/diff와 검증 결과를 전달합니다. 학습 후 실제 근거만 기록하고 검증한 뒤 커밋합니다. 읽기 권한이나 쓰기 권한이 없으면 필요한 파일을 제공하고 제안된 파일 변경을 사용자가 적용합니다. 별도 유료 API나 자동 연동 설정은 필요하지 않습니다.
