# 공개 자료 기준

커밋 전 변경된 모든 문서·JSON·교육 코드를 읽어 공개 권한을 확인합니다. API 키·토큰·비밀번호·개인 식별 정보·고객 데이터·비공개 업무/제품 코드·무단 제3자 자료는 저장하지 않습니다. 제품 코드 대신 허용된 URL·SHA·PR과 비식별 설명을 참조합니다. 참고 자료는 출처 링크를 제공하고 본문을 무단 복제하지 않습니다.

비공개 제품은 이름·URL·파일명·수치 자체가 민감할 수 있습니다. 공개 허용 범위가 확인되지 않으면 등록/사례 공개를 보류하고 비공개 작업 공간에서만 검토합니다. 예시를 실제 성과처럼 전환하지 않습니다. AI 제안과 학습자의 판단을 명시하고 측정하지 않은 수치를 넣지 않습니다.

portfolio의 공개 점검은 사람이 내용을 확인하고 기록하는 절차입니다. 자동 검사기는 비밀정보 탐지기나 사실 검증기가 아니므로 통과가 공개 안전성을 보장하지 않습니다. 노출 사고가 나면 관련 자격증명을 즉시 폐기/교체하고 Git 이력 정리와 피해 범위를 별도로 검토합니다.
