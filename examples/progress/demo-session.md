# 가상 학습 세션 — 실제 대화·평가가 아닙니다

날짜: 2026-11-17. 아래는 기록 방식 시연을 위한 창작입니다. 실제 사용자의 발언이나 수행한 테스트가 아닙니다.

## 실제로 학습했다는 가정

변수·함수·모듈·커밋·단위 테스트·응집도/결합도를 다루었다고 가정합니다. [사례 원본](../cases/demo-module-boundary.md)에 대응하는 시나리오입니다.

## 이해 확인 예시

- 변수: 가상 학습자 설명 “숫자 2+3은 5지만 문자열 '2'+'3'은 '23'이다.” Level 1 형식.
- 함수: 가상 설명 “subtotal은 price와 quantity를 받아 곱한 값을 반환하고 호출자는 그 값을 쓴다.” Level 2 형식.
- 모듈: 가상 설명 “CLI가 pricing을 import하고 pricing은 CLI를 참조하지 않는다.” Level 2 형식.
- 커밋: 가상 설명 “스테이징은 다음 스냅샷의 변경 선택이고 커밋은 이를 저장한다.” Level 1 형식.
- 단위 테스트: 가상 수행 “일반·0·음수 입력을 검사해 음수 수량 허용 오류를 찾고 예외 처리를 추가한 뒤 3개 테스트를 다시 통과했다.” Level 4 형식; 실제 실행하지 않음.
- 응집도/결합도: 가상 판단 “파일 하나는 탐색이 쉽지만 입출력 변화와 계산 변화가 엮인다. 작은 계산 모듈 하나면 독립 검사에 충분하며 서비스 분리는 과하다.” Level 3 형식.

## 미확인·보충·실제 적용 구분

다른 프로젝트에서도 판단 가능한지 확인되지 않았습니다. 실제 제품 적용은 없습니다. 응용이 필요할 때 보충하며 퀴즈는 가정하지 않습니다. 이 문서의 Level은 예시 데이터 연결용이며 실제 progress에 반영하지 않습니다.
