# 계산과 입출력 분리 — 가상 사례

이 문서의 구현·판단·검증은 모두 가상입니다. 원본 참조 형식은 [index](index.json)에만 저장하며 제품 코드가 존재한다고 주장하지 않습니다.

## 배경·기존 한계

하나의 CLI 파일에 입력 변환과 가격 계산이 섞여 있다고 가정합니다. 계산만 검사하려 해도 콘솔 입력이 필요합니다.

## 대안과 최종 선택

파일 하나를 유지하거나 계산 함수만 모듈로 분리하거나 별도 서비스를 만들 수 있습니다. 가상 AI는 세 대안을 제안하고, 가상 학습자는 테스트 가능성을 얻으면서 복잡성을 제한하기 위해 계산 모듈 하나를 선택합니다. 실제 사용자가 이 결정을 내렸다는 뜻이 아닙니다.

## 변경

가상의 pricing.py에는 순수 계산 함수를, CLI에는 입력·출력을 두는 시나리오입니다. 실제 코드 복제는 하지 않습니다.

## 검증과 결과

가상 명령: `python -m unittest -v`. Python 3.12에서 일반 수량·0·음수 수량 입력을 다룬다고 가정합니다. 처음에는 음수 수량을 허용해 실패하고, 유효성 검사를 추가한 뒤 3개 검사가 통과했다는 **예시 값**입니다. 실제 실행한 제품 테스트가 아닙니다. 성능·생산성 향상 수치는 측정하지 않습니다.

## 개념과 남은 한계

변수·함수·모듈·커밋·단위 테스트·응집도/결합도의 ID는 index를 참조합니다. 통합 테스트, 통화 반올림, 동시성은 이 사례 범위 밖입니다. 실제 역량 근거로 쓸 수 없습니다.
