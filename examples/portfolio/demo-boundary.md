# 모듈 경계와 회귀 검증 — 후보 형태 예시

**가상 데이터이며 실제 포트폴리오 성과가 아닙니다.** 원본은 [가상 개발 사례](../cases/demo-module-boundary.md), 상태는 [index](index.json)를 참조합니다.

계산과 입출력의 결합 문제를 발견하고 작은 모듈 분리와 회귀 검사로 접근했다는 이야기를 어떻게 소개할지 보여줍니다. 대안·판단 주체·테스트의 상세 내용은 원본에만 둡니다. 실제 사용자 기여나 측정된 성과는 없습니다. 공개용 후보를 등록하는 형식만 시연하며 실제 게시하지 않았습니다.
