# 작성 템플릿

- [knowledge](knowledge.md): `knowledge/<concept-id>.md`로 복사. 필요한 절만 확장.
- [session](session.md): `progress/<날짜>-<주제>.md`로 복사. 실제 관찰만 기록.
- [case](case.md): `cases/<case-id>.md`로 복사 후 index에 등록.
- [portfolio](portfolio.md): `portfolio/<후보-id>.md`로 복사 후 index에 등록.

JSON 필드와 값의 허용 범위는 [데이터 계약](../docs/data-contract.md), 연결된 완성 예시는 [examples](../examples/README.md)를 참고합니다. 템플릿의 미작성 부분은 완료 기록이 아니며 실제 문서에 필요한 값만 채웁니다.
