# 개발 사례

[index.json](index.json)은 사례 ID·날짜·개념·고정된 제품 변경 참조·문서 위치를 보관합니다. [사례 템플릿](../templates/case.md)을 복사해 `<case-id>.md`에 배경, 기존 한계, 대안, 선택, 실제 변경, 검증, 결과, 판단 주체, 남은 한계를 작성합니다. 인덱스 구조는 [데이터 계약](../docs/data-contract.md)을 따릅니다.

개념의 전체 정의나 프로젝트 소개는 반복하지 않습니다. 검증 결과는 명령·조건·관찰·한계를 적고 실행하지 않았다면 그렇게 명시합니다. 실패 사례도 보존할 수 있습니다. 학습 분석을 했다는 사실만으로 제품 수정 지시나 성과 주장으로 바꾸지 않습니다.
