# 공개 포트폴리오 후보

[index.json](index.json)은 사례 ID를 참조하는 후보 목록입니다. 사례 원본의 대안·검증·결정을 복제하지 않고, [템플릿](../templates/portfolio.md)으로 외부 독자용 소개와 배운 점을 작성합니다. 필드는 [데이터 계약](../docs/data-contract.md)에 정의합니다.

실제 문제 → 선택 근거 → 수행한 변경 → 관찰된 검증 결과가 있는 경험을 후보로 고릅니다. 단순히 강의를 읽거나 AI가 제안한 것은 성과가 아닙니다. `candidate → ready → published` 상태를 사용합니다. ready/published는 공개 점검 완료와 검증된 결과가 있는 사례만 가능합니다. published는 사용자가 실제 외부 공개한 뒤 기록하며 웹사이트를 자동 생성하지 않습니다.

정량 성과는 조건과 실제 측정값이 있을 때만 사용합니다. AI의 제안과 사용자의 결정을 구별하고 실패·한계를 감추지 않습니다. [공개 기준](../docs/publication.md)을 통과하지 않은 자료는 게시하지 않습니다.
